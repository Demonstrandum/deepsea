#              order, a stacked topic after its parent

#              branches, each declaring the harness topics it needs in its
#              plugins' package.json ("deepsea": { "requires": [...] }), so
#              starting a topic edits nothing here. See `dsd topics`.

#   upstream <tag>                      the upstream release (harness only); names
#                                       the integration branch, integration/<tag>
#   base <ref>                          what a topic without a parent is based on;
#                                       every integration starts from it
#   topic <branch> [<parent topic>]
